| Q1 | A slice bound and a list index convert through `__index__`, so a subscript IS an int conversion by the same protocol this checker uses. Should the class include them? Measured while building: including them needs a way to tell a derived bound from one that cannot be derived, and provenance is what decides it — `inputs[third : 2 * third]` in `token_thirds` is discharged because `third` is `len(inputs) // 3`, and `by_family[key][0]` indexes with a local name whose value the walk cannot see. So the two available rules are both wrong in one direction: exempt every `Name` bound and a derived bound passes; exempt none and the module is red today at a site nobody has measured a failure at | **Leave excluded** (what the branch does): the checker states the exclusion in its own docstring and in `token_thirds`', so a next editor meets it. Costs: a future `inputs[:derived]` is not caught. · **Include with a provenance pass**: a name is discharged when every assignment to it in the same unit is integer-shaped. Costs a real dataflow pass and a new class of false red. · **Include and require a guard everywhere**: smallest code, reddens the module today | Excluded, and stated | ⬜ |
| Q2 | Membership could be decided by *raising* rather than by converting: a site is a member when it raises on a value `count` admits — a non-finite float or an integer with no float of its own. That is strictly wider and it covers the OTHER half of round 3's defect, `sum(part) / len(part)`, where two derived integers raise `OverflowError` out of a true division that converts nothing. Measured while building: the wider predicate also flags `share`'s `part / whole * 100`, which is unguarded today and whose operands are durations in seconds — so taking it means changing a site #192 did not ask about | **Keep the chosen predicate** (what the branch does): the int conversion, as the ticket words it, with the division residual stated in `token_thirds`' docstring. · **Widen to raising**: catches the division route and needs a decision about `share` in the same change, which is a behaviour change outside #192's boundary. · **Widen and exempt `share`**: an exemption list, which is what this release exists to remove | The chosen predicate, with the residual stated | ⬜ |
