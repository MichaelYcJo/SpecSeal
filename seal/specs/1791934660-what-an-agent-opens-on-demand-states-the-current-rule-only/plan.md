## Summary

One branch, eight phases, one file or one coupled group per phase, each on #923's check and harness. Every phase partitions its file rule by rule first — contract, which stays with `Enforced by:`, or mechanics, which moves to the first sentence of its test's docstring or to the code's — and then rewrites to the contract alone. Phase 1 proves the batch shape on the file in every prefix, `CLAUDE.md` with its block template, and widens the record test so an on-demand file owes a record. Phase 2 takes the largest file. Phase 3 builds the orchestrator cases and their baseline, because phases 4 and 5 rewrite the orchestrating session's own instructions and nothing in #923's suite reads as that session. The former phase 6 (`skills/evidence-check/SKILL.md`, `templates/ledger.md`, `skills/evidence-ci/SKILL.md`, 63,595 B) is #944's deletion and is gone from this plan with every ledger, survivor and heading-anchor obligation. Every row only lowers; nothing asks a person; CI gains one test's scope and no job.

## Operational impact

- This branch rebases onto `release/v0.22.0` after #923 phases 1–2 and #944 phases 1–2 merge; every row this item touches lowers, so the pull request body carries no `Budget raised:` line. `BASELINE` entries shared with #941 and #923 are re-measured by whichever branch lands second.
- From phase 1 the block every session on a machine reads is shorter and points at `skills/implement/orchestration.md` for the routing procedure; a user's `~/.claude/CLAUDE.md` gets it at the next `install.sh` or `update`.
- From phase 5 every new work item's `routing.md` is ≈ 2.5 KB instead of ≈ 7; the standing copies are records and stay.
- A skill rule's home may now be a test docstring: a test renamed or deleted takes the rule's home with it, and the skill's `Enforced by:` fails #944's `enforced-unresolved` row, which is the signal.
- `tests/test_a_rewritten_definition_proved_non_inferior.py` demands a record for every file with a `bytes:` row that differs from the merge base, so #941's `docs/` phases and any later edit to one of these files owe a passing record or a census reason; #941 reads this before its next phase.
- No script, hook, checker or dependency is added beyond the case generator; test docstrings gain sentences; code docstrings gain the mechanics that left the skills.
