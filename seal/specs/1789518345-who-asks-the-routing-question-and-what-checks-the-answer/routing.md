## Why this way

Three issues are one question seen from three sides — #88 is what shape the
routing question takes, #419 is who asks it and what the framer is, and #399
is what checks that the answer was honoured. Built apart, the same question is
edited three times and the last is built against a moving target, which has
already happened once: #399's first frame keyed a check on a path floor, two
phases were built, and both were thrown away when the premise turned out
wrong.

The work changes an agent's instructions and adds a check, which is the
ladder's top rung, so the frame is drawn by a party that does not then build
to it. This file is itself written under the rule the work item is about to
change — the last time it is written this way.
