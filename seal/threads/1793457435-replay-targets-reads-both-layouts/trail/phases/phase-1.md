**The decisions this phase made, each with its grounds:**

1. **One statement of the layouts: `replay_targets.py#LAYOUTS`, two `Layout(root, rounds)` entries.** Each entry gives a record's path (`record`), its `routing.md` (`routing`), and the two path readers (`round_of`, `routed`). It also gives the text a message names the layout by (`named`). The layout before 0.23.0 is spelt on one line, under the one `old_names` exemption. Against: `frame/design.md` *Scope* item 1 and *Removes*, and `frame/plan.md` A2.
2. **`records` returns `{(item, n): (layout, text)}`, and `round_target` takes `layout=` as a keyword-only argument.** The layout is carried rather than the path. Then the next round's path, `routing.md` at the target and the report path are each derived from it, and none is parsed back out of a path. A target gains `report`, the record's own path, which both generators' `prompt` and `graders` read. Against: `frame/design.md` *Data & interfaces*, which leaves the return shape to the crafter.
3. **`seed_defects.py#target_of` is split into `round_1_of` and `target_at`, and `targets` returns a third value, `held`.** `held` is the number of commits whose round 1 record was read. Scope item 4 asks whether any commit holds a round 1 record. That is known where the record is read, and the alternative was to sort `target_of`'s reason strings into before and after the read. That would be the script parsing its own prose. `target_of` keeps its signature and result for its callers. Against: `skills/core/SKILL.md` *The first value: efficient development through the workflow* (a script reads what a command wrote).
4. **The empty-read line is printed where `--case` is not given; with `--case`, each name not written is said with its reason.** A `--case` run that reads nothing names each case as `no record of its work item was read`. So the empty read is said once per name and not twice. A name whose work item was read but whose round was not reads `no round <n> record of its work item was read`. This is the reading this phase took of `frame/design.md` *Scope* item 4.
5. **`Layout.routed` accepts only `<root>/<item>/routing.md`.** The old `SPEC` pattern also accepted a `routing.md` at any depth under a work item's directory. No release tag holds one in either layout (executed: `git ls-tree -r` over every `vX.Y.Z` tag, with a search for a deeper `routing.md`). So the narrowing changes no commit's reading.
