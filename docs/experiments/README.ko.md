# docs/experiments/ — 한 번 잰 것을 다시 재지 않도록

실험 하나에 파일 하나입니다. 읽어서는 답이 안 나오던 질문, 그 질문을 끝낸
방법, 그리고 결과가 무엇을 결정했는지를 적습니다. 여기서 확정된 플랫폼의
사실은 어떤 작업 항목보다 오래 살기 때문에, 그 사실을 필요로 했던 작업 항목
곁이 아니라 `docs/` 아래에 둡니다.

파일 이름은 `<날짜>-<무엇을-물었는가>.md` 로 짓습니다. 절은 아래 순서를
지킵니다. 답만 원하는 사람은 두 번째 절에서 읽기를 멈추기 때문입니다.

1. **질문** — 한 문장으로, 그리고 왜 읽는 것만으로는 답이 안 나왔는지.
2. **확정된 것** — 번호를 붙여, 각각 읽는 사람이 바로 쓸 수 있는 사실로.
3. **방법** — 다시 돌릴 수 있을 만큼. 원복하는 법까지.
4. **결과** — 돌린 순서대로, 각 회차가 무엇을 배제했는지와 함께.
5. **확정되지 않은 것** — 다음 사람이 어디까지가 경계인지 알도록.

나중에 특정 버전에서만 참인 것으로 드러난 결과는 고쳐 쓰지 않고 맨 위에
날짜 붙은 주석을 답니다. 그때의 측정은 그때는 참이었습니다.
